# 袋鼠数学竞赛测验网站 — 设计规格

**日期**: 2026-07-28
**目标用户**: 6-8 岁儿童（1-2 年级，袋鼠数学 Level 1-2），供家庭学习使用
**语言**: 中英双语（中文为主，关键数学术语与题目附英文）

---

## 1. 背景与目标

为准备袋鼠数学竞赛（Math Kangaroo）Level 1-2 的孩子打造一个互动测验网站，包含两大核心模式：

1. **闯关式练习**：逐题作答、即时反馈、图文解析，适合日常轻松练习
2. **全真模拟考试**：还原官方赛制（24 题 / 75 分钟 / 3-4-5 分阶梯计分），考前自测

附加能力：错题本、星星激励体系、家长统计面板。

### 官方赛制参照（Level 1-2）

| 项目 | 规则 |
|------|------|
| 题目数量 | 24 道选择题 |
| 选项数 | **3 个**（A/B/C，低年级赛制） |
| 考试时长 | 75 分钟 |
| 计分 | 第 1-8 题每题 3 分；第 9-16 题每题 4 分；第 17-24 题每题 5 分 |
| 起始分 | 24 分（避免零分） |
| 答错 | 倒扣 1 分；不答 0 分 |
| 满分 | 24 + (8×3 + 8×4 + 8×5) = 120 分 |

## 2. 技术架构

```
┌─────────────────────────────────────────────┐
│  Next.js 15 (App Router) + TypeScript        │
│  ┌───────────────────┐  ┌─────────────────┐  │
│  │ 前端页面            │  │ API Routes        │  │
│  │ React + Tailwind   │  │ /api/questions    │  │
│  │ 首页/练习/考试/错题本 │  │ /api/sessions     │  │
│  └─────────┬─────────┘  └────────┬────────┘  │
│            └──────────┬─────────┘             │
│            ┌──────────▼─────────┐             │
│            │ SQLite (better-sqlite3) │        │
│            │ data/quiz.db           │        │
│            └────────────────────┘             │
│  题库: questions/*.json  →  seed 脚本 → DB      │
└─────────────────────────────────────────────┘
```

| 层 | 选型 | 理由 |
|----|------|------|
| 框架 | Next.js 15 App Router | 全栈一体，前后端一个项目 |
| UI | Tailwind CSS + 手写动画 | 动画自由度高，无重型 UI 库负担 |
| 数据库 | SQLite（better-sqlite3） | 零配置，数据即单文件，易备份迁移 |
| 题库 | JSON 文件 + seed 脚本 | 题目以纯文本管理，家长可直接增改 |
| 读题 | Web Speech API（zh-CN） | 浏览器原生，为识字量有限的孩子朗读题干 |
| 部署 | 本地 `npm run dev` 或 Vercel | 任选，平板/手机/电脑皆可访问 |

**数据流**: 题库 JSON → seed 导入 SQLite → 页面经 API 取题 → 作答结果写回 DB → 错题本与统计读 DB。

## 3. 数据模型（SQLite，3 张表）

```sql
-- 题目表（seed 从 JSON 写入）
questions (
  id            INTEGER PRIMARY KEY,
  difficulty    INTEGER NOT NULL,      -- 3 | 4 | 5（每题分值）
  topic         TEXT NOT NULL,         -- counting|shapes|patterns|logic|arithmetic|time
  text_zh       TEXT NOT NULL,
  text_en       TEXT NOT NULL,
  illustration  TEXT,                  -- 插图描述符: "emoji:🍎🍎🍎" 或 "svg:mirror-triangle"
  choices       TEXT NOT NULL,         -- JSON: [{zh,en}, {zh,en}, {zh,en}]（固定 3 项）
  correct_index INTEGER NOT NULL,      -- 0 | 1 | 2
  explanation_zh TEXT NOT NULL,
  explanation_en TEXT NOT NULL
);

-- 每次练习/考试会话
sessions (
  id              INTEGER PRIMARY KEY,
  mode            TEXT NOT NULL,       -- practice | exam
  started_at      INTEGER NOT NULL,
  finished_at     INTEGER,
  score           INTEGER,
  max_score       INTEGER,
  correct_count   INTEGER,
  wrong_count     INTEGER,
  blank_count     INTEGER,
  duration_seconds INTEGER
);

-- 每题作答记录
answers (
  id                 INTEGER PRIMARY KEY,
  session_id         INTEGER NOT NULL REFERENCES sessions(id),
  question_id        INTEGER NOT NULL REFERENCES questions(id),
  chosen_index       INTEGER,          -- NULL = 未作答
  is_correct         INTEGER,          -- 0 | 1（未作答为 NULL）
  time_spent_seconds INTEGER,
  created_at         INTEGER NOT NULL
);
```

> 错题本与统计**不单独建表**，由 `answers` 派生，保证数据一致性。
> 星星数同样由 `answers` 派生：每题**首次**答对 +3⭐，同一题**再次**答对（练习中二次作答或错题本重做）+1⭐。

## 4. 功能模块

### ① 首页（冒险地图）
- 背景为澳洲内陆草原世界（分层天空、漂移云朵、绿色山丘、太阳）
- 袋鼠吉祥物"跳跳"站在起点，一条蜿蜒小径串联 4 个站点：
  🏃 闯关练习 · 📝 模拟考试 · 📒 错题本 · ⭐ 我的星星
- 顶部显示连续打卡天数与星星总数

### ② 闯关式练习（核心）
- 选择题型（6 大主题）或随机练习
- 逐题作答，3 个大号 A/B/C 选项按钮（平板手指友好）
- **第一次答对** → 彩带喷发 + 袋鼠跳跃 + 星星飞入星星罐（3⭐）
- **第一次答错** → 温和鼓励动画（不立即公布答案），给**第二次作答机会**；第二次答对得 1⭐
- **第二次仍答错** → 公布正确答案 + 双语解析卡片，该题进入错题本
- 🔊 读题按钮（speechSynthesis zh-CN 朗读题干）

### ③ 全真模拟考试
- 从题库随机抽 24 题（8×3 分 + 8×4 分 + 8×5 分），避开**上一次考试**已用过的题目（题库不足时回退为全量随机）
- 75 分钟倒计时，可前后切题、可标记不确定
- 交卷 → 按官方规则计分（起始 24 分 + 得分 − 答错扣分）
- 报告页：总分、分难度正确率、分题型正确率、每题耗时、鼓励性评语
- 结果持久化至 DB

### ④ 错题本 + 家长统计
- 错题列表逐题重做，答对即移出错题本
- 家长视图（算术密码门防孩子误触）：题型正确率雷达图、考试分数曲线、近期作答情况（纯 SVG 绘制，不引图表库）

## 5. 题库内容规划（约 50 道原创双语题）

按赛制分 **3 个难度档 × 6 大主题**，模拟考试按 8/8/8 抽题：

| 难度 | 分值 | 数量 | 定位 |
|------|------|------|------|
| 入门 | 3 分 | ~17 | 观察计数，一看就会 |
| 进阶 | 4 分 | ~17 | 转个弯，两步思考 |
| 挑战 | 5 分 | ~16 | 小陷阱，防粗心 |

**6 大主题**（每主题约 8 题）：

| 主题 (topic key) | 内容示例 |
|------|----------|
| 🔢 数数与观察 `counting` | 数图中物品、动物腿数、捉迷藏 |
| 🔷 图形与空间 `shapes` | 找不同图形、镜像、数三角形 |
| 🎨 规律与序列 `patterns` | 下一个图形/数字是什么 |
| 🧠 逻辑与推理 `logic` | 谁更高、排队位置、谁说谎 |
| ➕ 计算与应用 `arithmetic` | 钱币计算、分糖果 |
| ⏰ 时间与生活 `time` | 看钟表、星期几、书页码 |

**每题格式**: 双语题干 + 3 个双语选项（A/B/C）+ 双语解析 + 插图（emoji 或 SVG）。

**插图策略**:
- 简单计数题 → emoji 拼搭（🍎🍎🍎）
- 图形旋转、镜像、规律题 → 一组可复用的 SVG 绘图组件（程序化生成旋转/镜像）
- 所有资源内联，无外部依赖

## 6. 视觉与交互设计

**理念: "澳洲内陆冒险" 主题世界**——不是冰冷的测验系统，而是一片阳光草原。

### 配色

- 天空渐变 + CSS 动画漂移白云 + 底部绿色山丘 + 右上角柔光太阳

### 反馈动画
- 答对 → 彩带喷发 + 袋鼠跳跃 + 星星飞入星星罐
- 答错 → 选项轻摇头 + 袋鼠鼓励 + 展示正确答案与解析
- 星星罐渐满，达到里程碑点亮徽章
- 选项按钮按压下沉、悬停轻晃，触控目标足够大

## 7. 测试策略

- **题库校验脚本**: seed 时自动检查每题（3 个选项、correct_index 合法、双语题干/解析非空），任一题不合法即失败
- **计分逻辑单元测试**: 官方计分规则（起始 24 分、+3/4/5、答错 -1、不答 0）
- **手动测试清单**: 平板触控目标、读题功能、计时器准确性、离线可用性

---

## 8. 非目标（YAGNI）

- 多用户账号体系（单孩子使用，不做登录）
- 云端同步（本地 SQLite 即够）
- 复杂动画引擎（CSS + 少量 SVG 即可，不引 Lottie/Three.js）
- 图表库（雷达图/曲线用纯 SVG 手绘）
